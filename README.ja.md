[English](./) · [简体中文](README.zh.md) · [繁體中文](README.zh-TW.md) · **日本語**

RealSub は、パソコンで再生中の音声——動画、配信、ゲームなど——にリアルタイムで字幕を付ける Windows 用アプリです。音声認識はお使いのパソコン上で行われ、日本語・英語・中国語の間で翻訳することもできます。字幕はフローティングバーに表示されます。

システム全体の音声だけでなく、選んだ 1 つのアプリの音声だけを字幕にすることもでき、過去の字幕をスクロールして見返せます。フルバージョンでは SRT/MP3 の書き出しに対応。基本アプリは無料です。
