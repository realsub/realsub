RealSub 是一款 Windows 电脑实时字幕软件:电脑正在播放的声音——视频、直播、游戏等——都能实时生成字幕。语音在你自己的电脑上本机识别,并可在日语、英语、中文之间互译,字幕显示在悬浮条中。

可以收录整个系统的声音,也可以只收录你选定的某一个应用;还能上滚回看之前的字幕。完整版支持导出 SRT/MP3。基础版免费。
