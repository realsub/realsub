RealSub 是一款 Windows 電腦即時字幕軟體:電腦正在播放的聲音——影片、直播、遊戲等——都能即時產生字幕。語音在你自己的電腦上本機辨識,並可在日語、英語、中文之間互譯,字幕顯示在懸浮列中。

可以收錄整個系統的聲音,也可以只收錄你選定的某一個應用程式;還能往上捲動回看先前的字幕。完整版支援匯出 SRT/MP3。基礎版免費。
