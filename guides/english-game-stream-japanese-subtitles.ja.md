# パソコンで英語のゲーム実況・配信に日本語字幕を付ける方法(YouTube 以外も)

**日本語** · [ガイド一覧](README.ja.md)

海外のゲーム実況や配信を見ていて、「面白そうなのに何を言っているかわからない」と感じたことは
ないでしょうか。YouTube の動画なら自動字幕と自動翻訳である程度は追えますが、**Twitch や Kick
などの配信サイト**では、見る側で字幕を出す方法を自分で用意する必要があります。

このページでは、**サイトやプレイヤーを問わず**、パソコンで流れている英語の実況にリアルタイムで
日本語字幕を重ねる方法を紹介します。

---

## 字幕を付ける方法はいくつかある

YouTube 以外の配信で字幕を見る方法は、大きく分けて 3 つあります。

- **配信者側の字幕拡張機能。** Twitch には配信者が導入する字幕用の拡張機能があります。ただし
  配信者が設定している場合にしか使えず、見る側からは選べません。
- **ブラウザの字幕機能。** Chrome などのブラウザには、ブラウザ内で再生している音声に字幕を付ける
  機能があります。対応言語や翻訳の可否はブラウザのバージョンによって変わるので、使っている
  ブラウザの設定で確認してみてください。対象はそのブラウザの中の音声に限られます。
- **PC の音に字幕を付けるアプリ。** パソコンが再生している音そのものを文字に起こす方式です。
  サイトにもブラウザにも依存しないので、どこで見ていても同じように字幕が出ます。

このページでは 3 つ目の方法を紹介します。この方式なら、たとえば次のようなものにも字幕が付きます。

- Twitch・Kick・ニコニコ生放送などのブラウザ配信
- 配信のアーカイブや切り抜き動画
- Discord の通話や画面共有
- 英語音声のゲームそのもの

[RealSub](https://store.steampowered.com/app/5227410/) は、この方式の Windows アプリです。PC の
音声を取り込んで**手元のパソコン上で**英語を認識し、日本語に翻訳して、画面の一番手前に字幕バーとして
表示します。

---

## 手順

**1. インストールして、初回ウィザードで言語を選ぶ。**
聞く言語に「英語」、読みたい言語に「日本語」を選ぶだけです。認識モデルはアプリに同梱されているので、
追加のダウンロードもアカウント登録も API キーも要りません。

**2. 配信を再生して、字幕バーを見やすい位置に置く。**
音声ソースは初期設定のままで大丈夫です。PC で鳴っている音がそのまま字幕になります。

字幕バーはクリックを素通りさせるので、下の配信画面やゲームの操作を邪魔しません。マウスを乗せると
枠が出て、ドラッグで移動・幅の変更ができます。ゲーム画面の HUD やチャット欄と重ならない位置に
置いておくのがおすすめです。文字の大きさや色、不透明度は設定から変えられます。

あとは配信を見るだけです。英語の原文が話している最中から表示され、その下に日本語訳が続きます。

---

## 実況・配信ならではのコツ

- **ほかの音と混ざるときは、音声ソースを「配信を見ているブラウザ」にする。** 初期設定のままでも
  使えますが、自分でゲームを遊びながら配信を流している場合や、Discord で友達と話しながら見ている
  場合は、ゲーム音や通話の声も字幕に入ってしまいます。音声ソースで**特定のアプリ 1 つ**を選べば、
  そのアプリの音だけが字幕になります。(一覧には、一度でも音を出したアプリが表示されます。
  配信を再生してから選んでください。)

- **翻訳はローカル翻訳がおすすめ。** 実況は息継ぎなしで話し続けることが多く、文の区切りを待つ
  オンライン翻訳サービスでは訳文が遅れがちです。無料の「ローカル翻訳モデル」を入れると翻訳も
  PC の中で完結し、原文とほぼ同時に日本語が出ます。
- **英語の原文も一緒に見る。** 原文と訳文が上下に並ぶので、ゲーム用語やスラングで訳が怪しいときも
  原文で補えます。英語のリスニング練習にもなります。
- **配信の BGM やゲーム音が大きいときは、配信側の音量バランスに左右されます。** 声がはっきり
  聞こえる配信ほど、字幕も正確になります。
- **歌や BGM が中心の場面は、字幕が出たり出なかったりします。** 話し声を拾う仕組みのため、
  トークの場面ほど安定して字幕が出ます。

## よくある質問

**Twitch 以外でも使えますか。**
使えます。PC が再生している音に字幕を付けるので、配信サイトやプレイヤーの種類は関係ありません。

**英語のゲームを自分で遊ぶときにも使えますか。**
使えます。音声ソースにゲームを指定すれば、ゲーム内の英語の台詞に日本語字幕が付きます。

**英語の字幕だけ出すこともできますか。**
できます。翻訳をオフにすると、話された英語がそのまま表示されます。リアルタイムの文字起こしは
無料の本体で、期限も回数制限もなく使えます。

**音声はどこかに送られますか。**
音声は PC の外に出ません。認識は手元のパソコンで行われ、ローカル翻訳を使えば翻訳もオフラインで
完結します。詳しくは[プライバシーポリシー](../privacy.ja.md)をご覧ください。

**費用は。**
本体は無料で、リアルタイム文字起こしはフル機能で使えます。日本語への翻訳と履歴・書き出しは
DLC で解放されます。初回起動から 7 日間はすべての機能を試せます。
