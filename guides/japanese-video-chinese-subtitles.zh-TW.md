# 看沒有字幕的日語影片:怎麼即時出中文字幕(Windows)

[English](japanese-video-no-subtitles.md) · [日本語](english-video-japanese-subtitles.ja.md) · [簡體中文](japanese-video-chinese-subtitles.zh.md) · **繁體中文**

很多日語內容壓根沒有字幕軌。日本那邊的影片平台不少是不提供字幕的,直播更是從來沒有,老劇、
講座、訪談、播客也一樣——不是字幕組來不及做,而是**源頭就沒有字幕檔案**。機器翻譯的水平已經
夠用了,難點卡在前一步:**先把聲音變成文字**。

這篇講在 Windows 上怎麼做:挑工具該看哪幾點、我做的這個怎麼用,以及**它做不到什麼**。

---

## 挑工具看這 6 點

不管最後用哪個,合不合用基本由這幾條決定:

- **聲音從哪裡來。** 只能處理瀏覽器標籤頁裡影片的工具,碰不了本地播放器、下載好的檔案、
  直播客戶端、遊戲和通話。能抓系統聲音就全覆蓋;如果還能**只抓指定的某一個應用**,通知音和
  另一個視窗的聲音就不會混進字幕。
- **能不能同時看到原文和譯文。** 一邊看日文原文、下面跟著中文,和只看中文,是兩種完全不同的
  體驗。如果你順便還想學點日語,這一條最關鍵。
- **支援哪些語言組合。** 能出英文的工具很多,能翻成中文的少很多,**能區分簡體和繁體**的更少。
- **有沒有留下記錄。** 看過就算的話無所謂;但想回頭複習一段講座、或者把轉錄交給別人,就需要
  歷史記錄和匯出。
- **識別在哪裡跑。** 在自己電腦上跑意味著聲音不上傳、不按分鐘計費、也不擔心哪天服務關停。
- **對電腦的要求是什麼。** 有些功能是被**你事後加不上去的硬體等級**卡死的;有些只要一塊你
  大機率已經有的顯示卡。

### 先試試你已經有的

Windows 自帶**即時字幕**(**Win + Ctrl + L**)。取決於你的硬體和 Windows 版本,它可能已經能
滿足一部分需求,而且不花錢。它的能力每個 Windows 版本都在變,所以請看
[微軟官方頁面](https://support.microsoft.com/zh-tw/windows/%E4%BD%BF%E7%94%A8%E5%AE%9E%E6%97%B6%E5%AD%97%E5%B9%95%E6%9B%B4%E5%A5%BD%E5%9C%B0%E7%90%86%E8%A7%A3%E9%9F%B3%E9%A2%91-b52da59c-14b8-4031-aeeb-f6a47e6055df)
確認當前支援情況,而不是任何第三方的對比文章(包括本文)。夠用的話,你不需要再裝別的。

瀏覽器外掛適合「要看的東西全在瀏覽器裡」的人,注意其中不少會把聲音傳到伺服器。雲端轉寫服務
精度不錯,但要上傳檔案、等結果,**幫不了你今晚這場直播**。

## RealSub 怎麼用

[RealSub](https://store.steampowered.com/app/5227410/) 抓取電腦正在播放的聲音,**在本地**識別成
文字,可選翻譯,然後用一條點選穿透的字幕條顯示在所有視窗最上層。本體免費,轉錄不限次數。

**1. 裝好、走一遍首次執行嚮導。** 它會檢查硬體,然後問兩個語言:你在聽的(日語)和你想讀的
(中文,簡體或繁體)。識別模型內建在軟體裡,不用下載、不用註冊、不用 API key。

**2. 選聲音來源。** 整機,或者**指定某一個應用**。後者值得花一分鐘學會:選中播放器或瀏覽器,
就只有它的聲音進識別,QQ / Discord 的提示音、後臺另一個影片都不會混進字幕。沒出過聲的應用
不會出現在列表裡。

**3. 開始播放,擺好字幕條。** 字幕條點選穿透,不擋下面的播放器操作。滑鼠懸停會浮出邊框,可以
拖動和縮放;字型、字號、顏色、不透明度都在設定裡。

你會看到日文原文在對方還在說的時候就出現,中文譯文**慢一拍**跟上。

### 硬體,說實話

識別跑在顯示卡上。**GTX 10 系、2GB 顯示記憶體起步**,4GB 以上更從容。A 卡和 Intel 核顯走 Vulkan,
首次執行會做一次簡短的效能測試,透過了才啟用。沒有可用顯示卡時退到 CPU 模式、換用較小的模型——
能用,但精度明顯下降、延遲明顯變長。它沒有「轉去雲端」這條後路,這是有意的:聲音不出你的電腦。

## 它做不到什麼

裝之前先知道:

- **譯文比原文慢一拍。** 它按整句翻譯,要等一句說完。正常對話差幾秒;連續說話的場合(解說、
  講座、直播)可能拖到十秒左右。這是「翻整句而不是翻碎片」的代價,不是網路或效能問題。
- **唱歌和純音樂不出字幕。** 歌曲、以及做成廣播效果的人聲會被判為非語音,根本到不了識別器。
- **識別離線,翻譯要聯網。** 除非你在自己的電腦或區域網裡跑一個翻譯服務。發出去的只有識別後的
  文字,音訊不傳送。
- **機器識別 + 機器翻譯,一定有錯。** 口音重、多人搶話、語速快的時候錯得更多。它是幫你聽懂,
  不是給你出一份可以存檔的字幕。
- **只有 Windows**(10 版本 2004 以上,64 位)。macOS 版在計劃中,沒有日期。

## 關於準確率

在我自建的測試集(TED、新聞、動畫、講座、直播錄影)上測出來是**日語 92%、英語 98%、
中文 93%**。這是我自己測試集上的內部數字,不是什麼官方跑分,實際能到多少完全取決於素材:
單人清晰講話遠高於這個數,帶 BGM 的多人閒聊低於這個數。

唯一靠譜的判斷方式是**拿你自己常看的東西試十分鐘**。轉錄在免費版裡不限次數,就是為了讓你先
試過再決定翻譯值不值得花錢。

## 常見問題

**什麼播放器都能用嗎?**
它取的是 Windows 正在播放的聲音,所以跟播放器無關——本地播放器、瀏覽器、直播客戶端、下載的
影片、遊戲都一樣。

**能只出日文字幕、不要翻譯嗎?**
能,而且這部分免費。關掉翻譯就只出日文原文,學日語的人要的往往正是這個。

**聲音會被上傳嗎?**
音訊永遠不會。開著翻譯時,只有識別出來的文字會發給你選的翻譯服務;關掉翻譯、或者指向你自己的
本機服務,就什麼都不出去。[隱私政策](../privacy.zh-TW.md)裡按路徑逐條寫明瞭。

**多少錢?**
本體免費:完整的即時轉錄,不限時間、不限次數。**翻譯**和歷史匯出由一次性 DLC 解鎖。首次使用起
有 7 天全功能試用。
